# Daily Budget – notes for Claude Code

Personal iPhone budget app, used by one person. Data lives on the phone (SwiftData) and, when signed in, is backed up to the owner's own server. No third-party libraries without asking.

- Stack: Swift, SwiftUI, SwiftData, iOS 17+. Project file is generated by XcodeGen from `project.yml` (never commit `.xcodeproj`).
- Money is stored as integer cents. All budget math goes in `Logic/BudgetCalculator.swift` and gets a unit test in `DailyBudgetTests/`.
- Design ("Calm", chosen 2026-11-14 to look professional; replaced the Ledger serif and dark glass). One Apple-style design for both modes via `Color(light:dark:)`: SF Pro only (`Theme.rounded` is SF semibold, amounts `.monospacedDigit()`), sentence-case labels (no all-caps), grouped lists on plain `.glassCard()` surfaces (Theme.card, radius 12, no border, no shadow), quiet icons (`CategoryIcon` = accent symbol on accent tint, same for every category; colour only means good/over), standard tab bar tinted with the accent. Light: background #F2F2F7, surfaces white, ink #111A12, forest green accent `mint`/`primary` #2E5E3E, tomato `warn` #C0392B. Dark: navy #0F1A2E, surfaces #17253D, ink #EEF2F7, powder blue accent #A9CBE8, soft tomato #F07A62, sunflower `Theme.highlight` #F5C542 only for the + button. History shows this month day by day (`TrendCard`). Tips like the swipe hint show only for new users. Widget palette `W` in DailyBudgetWidget.swift mirrors it.
- Plan data (seeded on first launch, editable in app): $4,700 total, Nov 2026–Apr 2027. Monthly bills: Bank $200, Electricity $100, Wifi $18, Waste $5. Water $5 in Nov and Feb. Credit card $700 once in Dec. Engagement $1,500 set aside. Living money $92/month.
- Rules: today's limit = living money left this month ÷ days left (rollover); Bills and Engagement categories don't count as living; month leftover goes to emergency savings.
- Design reference: https://claude.ai/artifact/Lk8Nh7N1s9pdU5EHPQkdeb · Build plan: https://claude.ai/artifact/1YqRdhWzEcXRioubV5Na7V
- Home-screen widget (`DailyBudgetWidget/`) shares `Logic/BudgetCalculator.swift`, `Logic/MonthKey.swift` and `Shared/` with the app; the app writes a `WidgetSnapshot` to App Group `group.com.pensereyotdom19.dailybudget` (see `Models/AppRefresh.swift`), which also reschedules reminders.
- Backup & sync (`Sync/`): optional sign-in to the backend at https://daily-budget-api.onrender.com (repo: ../daily-budget-api, Spring Boot). The phone stays the source of truth and works offline. `SyncEngine` finds changes by comparing each record's fingerprint with `SyncState` (Application Support/sync-state.json), uploads with idempotent PUT/DELETE by the phone's UUIDs, then downloads `/api/sync?since=`. Login token lives in the Keychain (`SessionStore`). `SyncManager` syncs on launch, 3 s after any save, and when the app goes to background. Views don't need to call anything when they change data. Sync tests use a fake server (`DailyBudgetTests/SyncTests.swift`); keep it in step with the backend.
- Extra income (`Income`: living / savings / engagement), monthly `RecurringExpense` (with `lastAddedMonth`, so a restore never adds one twice), and new-plan fields (`BudgetSettings.historyStartMonth`, `savedBeforeCents`) sync like the rest (`/api/incomes`, `/api/recurring`, settings). Riel rate, Face ID lock and reminder switches are per-phone UserDefaults.
- Languages: English + Khmer in `DailyBudget/Localizable.xcstrings`, generated — don't edit it by hand. After changing UI text: build once, add the Khmer to `tools/km_translations.py`, run `python3 tools/make_strings.py` (it fails on any missing translation or changed placeholder), then build again. Text passed to our own views should be `LocalizedStringKey`; text built as a String uses `String(localized: "...", bundle: AppLanguage.bundle)` so the in-app language switch (Settings tab, `Shared/AppLanguage.swift`) applies, and dates use `.locale(AppLanguage.locale)`.
- Widget buttons and Siri/Shortcuts (`Models/SiriIntents.swift`) don't touch SwiftData: they queue `PendingExpense`s in the App Group (`Shared/QuickAddQueue.swift`), and `QuickAddImporter` saves them when the app opens (same id, so never twice).
- Free-Apple-ID expiry is read from the app's own `embedded.mobileprovision` (`Logic/AppExpiry.swift`) for the Settings card, Today banner and reminder.
- Subscriptions (`Subscription`, `Logic/SubscriptionSchedule.swift`) are paid like bills: `SubscriptionRunner` adds each renewal as a `.bills` expense on its date and moves `nextRenewal` on (anchor day keeps the 31st). They count in planned costs and sync via `/api/subscriptions`. Today hides all `.bills` expenses.
- Bills with a `dueDay` are paid automatically by `BillAutoPay` (on open) on that day of each due month, dated that day; `lastAutoMonth` makes a manual untick stick. Bills without one are ticked by hand. Reminders: day before for auto bills, 1st/25th for the rest.
- Screenshots: iPhone 17 simulator (iOS 27.2) — build with `-destination id=DC114D9A-BBAA-4874-BC76-E3A8FD3306E6 -derivedDataPath build/DDsim`, `simctl install`, launch with `-sampleData YES` (debug-only sample week) plus `-startTab history|plan|settings`, `-openAdd YES`, `-openSubscriptions YES`; `simctl io <id> screenshot`. Don't install on the owner's phone unless asked.
- Expense rows: `.expenseSwipe(e)` (left delete, right add again). App icon: `swift tools/make_icon.swift DailyBudget/Assets.xcassets/AppIcon.appiconset` (light, dark, tinted). Control Center buttons live in the widget (iOS 18); their intents are in `Shared/ControlIntents.swift`. Khmer catalog: `STRINGS_BUILD=build/DDsim python3 tools/make_strings.py` after a simulator build.
